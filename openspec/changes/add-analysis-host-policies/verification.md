# Verification evidence

This map connects every delta scenario to executable evidence. Test names are exact. `coordinator-races.test.ts` uses controlled sessions for deterministic ordering inside a real Extension Development Host; it complements rather than replaces the real spawned-session scenarios in `coordinator.test.ts`, `orchestration.test.ts`, and `logging.test.ts`.

Paths used below:

- **Engine**: `packages/cem-analyzer-ts7/test/`
- **Core**: `packages/analyzer-core/test/`
- **Editor**: `packages/vscode-extension/src/test/`
- **Probes**: `openspec/changes/add-analysis-host-policies/probes/`
